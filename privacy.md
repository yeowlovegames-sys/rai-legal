# Privacy Policy for Rai
**Last Updated:** 11/20/2026

This Privacy Policy explains how **Rai** ("the Bot") collects, stores, and uses data when you interact with it on Discord.

## 1. Data We Collect and Store
To provide moderation, utility, fun, and anime features, the Bot stores the following information in its database:
* **Server Configuration Data:** Server IDs, Channel IDs, Role IDs, and custom settings saved through configuration commands.
* **Moderation & Mute History:** User IDs, Moderator IDs, mute durations, reasons, and timestamps.
* **Message Logs:** Message content, Message IDs, User IDs, Channel IDs, and timestamps when server administrators enable message logging (such as edited or deleted message logs).

## 2. How We Use Your Data
We only use stored data to operate the Bot’s core features:
* Enforcing server moderation actions and tracking mute histories.
* Sending configured message logs to designated server log channels.
* Remembering server-specific preferences and settings.

## 3. Data Storage and Security
* All collected data is stored in a database hosted via **WispByte** infrastructure.
* We do not sell, rent, or trade your data to third parties or advertisers.
* Data is only accessible to the Bot developer for maintenance and debugging purposes.

## 4. Data Retention and Deletion
* Configuration data and logs are kept only as long as needed for the Bot to function in your server.
* **How to request deletion:** Server owners or users can request the removal of their stored data (such as mute history or server configs) by contacting us at **[Contact the developer on Discord](https://discord.com/users/1556682310705877077)**.

## 5. Changes to This Policy
We may update this Privacy Policy as new features are added. Continued use of the Bot after changes means you accept the updated policy.
